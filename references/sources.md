# Sources and research basis

This skill is a synthesis. The sources below informed the structure and defaults. They are references for judgment, not dependencies that must be copied into every product.

## Agent-skill and pipeline references

- [VibeCurb](https://github.com/Yu-369/VibeCurb) — staged image exploration, brand generation, screen generation, and visual drift checks.
- [Taste](https://github.com/Leonxlnx/taste-skill) — concrete visual dials, defaults, and anti-generic output guidance.
- [Impeccable](https://github.com/pbakaus/impeccable) — focused UI quality and refinement workflow.
- [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) — broad design reference coverage and decision tables.

- [Superpowers](https://github.com/obra/superpowers) — staged brainstorming, planning, execution, and review.
- [Agent Skills specification](https://github.com/agentskills/agentskills) — portable `SKILL.md` convention.
- [OpenAI design skills](https://github.com/openai/skills) — token and component-led design-to-code workflow.
