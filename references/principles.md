# Principles

Use these principles to choose between plausible solutions. They are decision rules, not a visual preset.

## Foundation

| Principle | Default behavior |
| --- | --- |
| Purpose | Every screen has one primary job. Remove elements that do not help that job. |
| Agency | Make the next action clear. Let users undo, cancel, go back, and understand consequences. |
| Responsibility | Make status, cost, privacy, permission, failure, and irreversible effects visible before commitment. |
| Familiarity | Prefer conventions users already understand. Add novelty only when it improves the task. |
| Flexibility | Support compact and wide surfaces, keyboard or platform input, varied content lengths, and different abilities. |
| Simplicity | Reduce steps, choices, and visual noise without hiding necessary information. |
| Craft | Align details, states, copy, motion, and assets. A polished happy path with broken states is unfinished. |
| Delight | Add warmth through timing, copy, and meaningful feedback. Do not add decoration that competes with the task. |

These are the operational form of Apple's human-interface foundation. The agent should be able to point to the rule that supports a decision.

## Product discipline

Use Linear's working habits for design decisions:

- Start with the user's problem and desired outcome.
- Make the smallest coherent system that supports the product.
- Use a short screen brief before generating a screen.
- Prefer a clear, purpose-built flow over a large option set.
- Explore alternatives only while the decision is unresolved.
- Verify the result against the task, not just the image.
- Keep a decision log so accepted direction does not drift.

## Decision test

For a design choice, ask:

1. Does it improve the user's primary task?
2. Is it familiar enough to understand without explanation?
3. Does it survive light, dark, compact, wide, empty, slow, and error states?
4. Is it accessible without color, hover, sound, or motion?
5. Can the decision be written as a reusable rule?

If the answer is no to several questions, keep exploring.
